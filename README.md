# JACsPOT

JAGをベースに開発する、ブラウザ向けパチンコゲームです。

## ローカル起動

```powershell
npm run dev
```

起動後、`http://127.0.0.1:8787/jackspot` を開きます。

## 検証

```powershell
npm run check
```

ゲーム本体は `jackspot.html`、ガイドは `jackspot_guide.html` です。

開発中は通常URLでも画面右下にデバッグボタンを常時表示します。公開時は `JACKSPOT_DEVELOPMENT_MODE` を `false` に変更すると、`?debug=1` を指定した場合だけ表示されます。

## JACsPOTゲームフロー

1. 中央1ラインの1ゲームにつき100ptをCREDITから使用します。
2. 左・中リールは7のみ、右リールは7と空白が交互に並びます。
3. 成立役は中央ラインの777、またはハズレの2種類だけです。
4. 777が揃うとリール面が暗転し、PAYOUT ROULETTEがリール窓内へ拡大表示されます。
5. 1stステージは200pt・500pt・750pt・UPを3組並べた12マスから開始し、UPなら2ndステージへ昇格します。
6. 2ndステージは1,000pt・1,500pt・2,000pt・UPを2組並べた8マスで、さらにUPならFINALステージへ昇格します。
7. FINALステージは5,000pt・10,000ptの2マスです。
8. 最終停止位置の払い出しをCREDITへ加算します。

ルーレットの払い出し候補は `JACKSPOT_ROULETTE_PAYOUTS` で管理します。
